💻 Real-Time Collaborative Coding Platform

A web-based platform that enables multiple users to collaborate on code in real time, share coding rooms, and communicate through integrated chat.

✨ Features

- 👤 User Registration & Login
- 💻 Real-Time Code Synchronization
- 👥 Collaborative Coding Rooms
- 💬 Real-Time Chat
- 🔐 Secure Password Hashing
- 🗄️ Database Integration

🛠️ Technologies Used

- 🐍 Python
- 🌐 Flask
- ⚡ Flask-SocketIO
- 🗄️ Flask-SQLAlchemy & SQLite
- 🔑 Flask-Login
- 🎨 HTML, CSS & JavaScript
- 🔌 Socket.IO

⚙️ Installation & Setup

**1. Clone the repository**
```bash
git clone https://github.com/jmythri1234/Real_Time_Collaborative_Coding_Platform.git
```

**2. Navigate to the project**
```bash
cd Real_Time_Collaborative_Coding_Platform
```

**3. Create and activate a virtual environment**
```bash
python -m venv venv
venv\Scripts\activate
```

**4. Install dependencies**
```bash
pip install -r requirements.txt
```

**5. Run the application**
```bash
python app.py
```

🌍 Open **http://127.0.0.1:5000** in your browser.
